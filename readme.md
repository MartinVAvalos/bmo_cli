# After running bmo. To navigate you have:

## Normal Picker Controls

- Up and Down key to move up or down your options.
- Left to increase a counter by 10. Selecting up or down will navigate by (10 \* number of times left was clicked)
- Right reveal contents of a folder
- Space to select/deselect files or folders
- Enter to confirm selection
- Esc to cancel

## Search Mode

Press `i` to enter search mode for quick file/folder filtering:

- `i` - Enter search mode
- Type - Filter by file/folder path (case-insensitive substring match)
- Backspace - Remove search characters
- Up/Down arrow - Move one search result
- Left/Right arrow - Jump through search results (10 at a time)
- Space - Select/deselect a result (selections persist)
- Esc - Exit search and return to normal tree

**Note:** Selections made while searching remain selected after exiting search mode.
